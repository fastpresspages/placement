The 90-day plan

Four phases. Miss a day? Miss a week? Resume, don't restart. The plan flexes, your excuses don't get to run it.

Days 1-14

Foundations

Pick one language (Python or JavaScript). Learn HTML/CSS/JS basics or Python basics properly. Learn Git and push daily.

Milestone: a GitHub profile with a profile README and 10+ small commits.

Days 15-45

DSA core

Start the NeetCode roadmap or Striver's A2Z sheet. One focused session daily. Understand, don't memorize — explanation beats speed.

Milestone: 60-80 problems solved, your two weakest patterns identified.

Days 46-75

Flagship + mocks

Build one real project people can use (not a to-do app). Interview mocks with a friend or AI. Resume from day 60.

Milestone: deployed project with README, screenshots and honest docs.

Days 76-90

Apply & loop

Applications go out daily now. Track every one. Each rejection gets the same treatment: what was asked, what to drill next.

Milestone: 20+ targeted applications, 3+ mock interviews done.

Week-by-week from zero (if you are starting from scratch)

Weeks 1-2: HTML, CSS, basic JS or Python syntax. Git everyday. Weeks 3-4: First mini projects + first 20 easy DSA problems. Weeks 5-8: Core DSA daily + start the flagship idea. Weeks 9-10: Flagship v1 live + resume published. Weeks 11-12: Apply daily + mocks + keep one open-source PR alive. Repeat the last two weeks until offers land.

The nice-and-free mindset

Placement culture is stressful enough without people making it worse. Be the person who:

Helps one person a week

Explain something you just learned to a junior. Teaching is the fastest review there is — start with the friendly culture of first-time contributions.

Never fakes it

No fabricated experience, no copied projects, no paid certifications pretending to be skills. Interviewers have seen it all — real beats polished.

Shares everything free

Know a good free resource? Add it here. This list lives on pull requests. Gatekeeping knowledge is how mediocrity survives.

Stays sane and kind

Rejections are the norm in placements. Rest is part of the plan. Compare yourself to yesterday's you, never to someone's highlight post.

Honest questions, honest answers

Is everything really free?

Yes. Links point to free resources; we never promote paid courses, referral links or affiliate deals. FastPress Labs' own paid consulting is a separate thing that doesn't hide behind this page.

I am not from a CS background. Can I still get placed?

Yes. Skills beat degree labels in most modern hiring. Start at Foundations, follow the plan, build in public. One real project outweighs ten certificates.

How long does prep actually take?

2 to 6 months of consistent work, depending on your starting point. The 90-day plan is a structure, not a promise.

Why is this free?

FastPress Labs builds free launch tools in the open; people who like them hire us for paid work. Teaching for free earns that trust. No catch, no upsell inside these links.
